# ABACUS+LibRPA Strict-2D Ewald And Head/Wing

Use this skill for the production strict-2D GW path. Use the general ABACUS+LibRPA GW, host, build, and version-guard skills as needed. Do not apply the direct complete-`Wc` rules below to a 3D bulk calculation. For RPA total energies, use the dedicated RPA skill and verify its head/wing mode separately.

## Fix The Calculation Identity First

1. Start from the latest clean local `master_ghj` of both ABACUS and LibRPA. Make future fixes there; do not create a second production feature branch.
2. Require the selected ABACUS commit to contain `ef161c3e3608d15e206cc53b30826ac31805e522` and the selected LibRPA commit to contain `9ed00e4ca8da1f80ecd2c57802d4d45908fb1ccc`, or a documented later replacement that passes the same strict-2D tests.
3. Build separately for each host. Record source commit, clean/dirty state, absolute executable path, executable SHA256, host, run directory, and job id. Architecture-specific executable hashes may differ; source identity and tested behavior must agree.
4. Treat a binary change as a new numerical series. Run one matched symmetry/full-q gate before expanding it.

Do not trust a branch name or an old dated binary by itself.

## Use The Strict-2D Physics Route

- At every finite `q`, use the full 2D Ewald Coulomb matrix for epsilon and `Wc`.
- At Gamma, average the complete correlation screened interaction over the actual Gamma cell:

  ```text
  average_Gamma[Wc] = average_Gamma[
      sqrt(V_full(q)) (epsilon_inverse(q) - I) sqrt(V_full(q))
  ]
  ```

- Do not average `epsilon_inverse-I` first and then attach a numerical `q=0` Coulomb value.
- Do not use spherical Spencer truncation, projected cut Coulomb, or a `vq_cut` route for the strict-2D result. Keep `vq_threshold = 0`.
- Describe the analytic response in the plane-wave representation and the final result in the auxiliary-basis representation. The transformation between them is computed from the producer metadata and the Gamma full-Ewald Coulomb basis.

Read [parameters-and-gates.md](references/parameters-and-gates.md) for the formulas, exact input blocks, required files, and output gates.

## Prepare One Inseparable Producer Bundle

Run ABACUS with `out_librpa_reader_version 1`, `rpa 1`, `exx_singularity_correction massidda`, and `exx_ewald_dimension 2`. Keep the following from the same producer:

- `stru_out`, `bz_sampling_out`, wave-function and auxiliary basis files;
- full-Ewald Coulomb files, LRI coefficients, shrink files, and IBZ eigenvectors;
- `librpa_2d_coulomb_head.dat` generated by ABACUS;
- symmetry files when symmetry is enabled;
- full regular-grid PyATB data generated from this producer.

The metadata file is required by the current reader, but its values are not user parameters. Never edit, fit, or copy it from another producer. ABACUS computes it from the in-plane area and auxiliary-basis monopole moments; LibRPA recomputes the normalization and checks the area against `stru_out`.

Do not mix a symmetry producer's Coulomb/LRI/eigenvector files with a full-q `stru_out`, or vice versa. Matching lattice constants and basis dimensions are insufficient proof.

## Generate Head/Wing Data

Generate PyATB data on the full regular k grid belonging to the producer. IBZ points and k-star weights are not a substitute for the full grid required by the analytic head/wing sums.

Require matching full-grid k count, state count, basis size, spin/SOC mode, and nonempty velocity and wave-function data. For a band calculation, use a semantically matched current-ABACUS band source. A 121-point path is the current project plotting convention, not part of the strict-2D formula.

## Run LibRPA

Use the production input in the reference file. The hard switches are:

```text
option_dielect_func = 3
replace_w_head = t
use_pyatb = t
use_2d_dielectric = t
use_fullcoul_eps = t
use_fullcoul_wc = t
use_scalapack_gw_wc = t
vq_threshold = 0
libri_chi0_threshold_C = 1e-4
libri_chi0_threshold_G = 1e-5
libri_g0w0_threshold_C = 1e-5
libri_g0w0_threshold_G = 1e-5
libri_g0w0_threshold_Wc = 1e-6
```

For the current convergence profile, also use `nfreq = 16`, fixed `n_params_anacon = 12`, and the default option-0 quasiparticle equation solver. Omit `option_qpe_solver`, or set it explicitly to `0` only if supported by the selected build. Do not silently use option 2 (the linearized `Z` form).

The five LibRI screening thresholds above are the OhMyLibRPA production defaults for `chi0` and real-space `Sigma_c` construction. Require them explicitly in every newly staged strict-2D GW input, including head/wing-off controls. Do not rely on LibRPA's zero-valued compiled defaults. They reduce negligible real-space blocks and can materially lower runtime, but they are numerical approximations rather than physical parts of the 2D head/wing treatment.

Changing any of these thresholds defines a new numerical series. Before extending an existing all-zero-threshold campaign, run one matched anchor with the five production thresholds and compare the first-PBE-indexed frontier, band topology, gap, high-state NaNs, and strict-2D route diagnostics against the accepted zero-threshold anchor. Do not mix threshold-enabled and all-zero points in one convergence curve until that gate passes. Tighten one threshold family at a time if the anchor is sensitive.

## Validate In Order

1. **Version gate:** source ancestry, clean build provenance, executable hashes.
2. **Producer gate:** converged SCF, expected IBZ/full-grid counts, complete reader-v1 Coulomb/LRI/basis/symmetry files, valid generated normalization metadata.
3. **PyATB gate:** exact producer identity and complete full-grid head/wing data.
4. **Band-source gate:** same physical structure, PP/orbital basis, state count, spin/SOC convention, and complete path data.
5. **LibRPA route gate:** exact input echo, all five nonzero LibRI `chi0`/`g0w0` screening thresholds, and all required complete-`Wc` runtime markers.
6. **Numerical gate:** solver success, finite first-PBE-indexed frontier states, stable Pade roots, nonempty KS/EXX/GW bands, and separately reported high-state NaNs.
7. **Physics gate:** matched symmetry/full-q agreement, then k-mesh, vacuum, orbital, and auxiliary-basis convergence as required.

Scheduler completion alone does not pass any downstream gate. A failed wrapper after solver success is not automatically a physics failure; inspect the immutable artifacts before deciding whether to rerun.

## Fail Closed

Stop rather than falling back when any of these occurs:

- missing or manually changed `librpa_2d_coulomb_head.dat`;
- cut Coulomb selected for epsilon or `Wc`;
- missing complete-`Wc` Gamma marker or missing skipped-factorized-`q=0` marker;
- mixed producer/symmetry artifacts or mismatched k-star count;
- incomplete full-grid PyATB data;
- missing or zeroed LibRI `chi0`/`g0w0` screening thresholds in a newly staged production input;
- non-finite first valence or first PBE-indexed conduction state;
- symmetry not checked against a matched full-q control for the current binary series.

Keep diagnostic overrides, alpha/omega modifications, and experimental continuation choices out of production inputs.
